# Kreader 听书

Kreader 的“听书”入口位于阅读器顶栏。

- **Windows**：使用 Windows SAPI 已安装的本地语音，生成 WAV 后在应用内播放。
- **macOS**：使用系统 `say` 已安装的本地语音，生成 WAV 后由 AVFoundation 播放。
- Windows、macOS 的朗读和试听均在本机完成，不上传正文、不调用 Edge TTS，也不自动安装 Python 或 edge-tts。旧的在线音色设置会回退到已安装的本地音色；可在听书设置中重新选择。
- 如果缺少所需语言的语音，请在系统设置中安装后刷新语音列表。下载系统语音包可能需要联网，安装完成后朗读无需联网。
- Windows、macOS 的听书设置还提供可选的离线语音包：Kokoro v1.1-zh（int8 或 fp32，103 个中英音色）和 MeloTTS 中文/英文（单音色）。在“离线语音包”中选择型号后手动下载，资源仅从 GitHub 官方 Release 获取，并按内置 SHA-256 校验后安装；不镜像、不自动下载。安装完成后音色会出现在语音列表中，朗读仍完全在本机完成。语音包可随时删除。
- 语音列表默认只显示少量推荐音色（Kokoro 中文女声、中文男声、英文女声、MeloTTS，以及系统中文/英文语音）；勾选“显示全部声音”可浏览全部系统语音和已安装语音包的说话人。系统趣味音效默认隐藏，当前选中的声音在切换显示范围后仍会保留。
- 本地语音支持语速和音量；当前不支持独立音调调节。
- Linux 暂时保留原有 edge-tts 在线引擎，其朗读文本会发送给微软，首次使用可能安装相关依赖。

朗读按正文自然边界分段，当前片段会在 Kreader 中高亮；勾选“自动朗读下一章”后，章节结束会继续播放下一章。手动翻章、关闭阅读器或返回书架会停止播放。PDF 仅支持可提取文本的页面。
