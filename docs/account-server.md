# Libzora 分区账号与最小权益验证服务

账号服务仅保留功能权益验证所需的账号认证与邮箱恢复、区域隔离、6 台设备 / 会话 / 封禁安全、试用领取与到期、账号权益开通 / 撤销与校验，以及必要的管理认证、CSRF 和审计。永久权益由受保护的管理员操作按外部授权直接开通到账号，客户端不能自行授予权益。服务端不处理产品、订单或支付，不提供激活码生成、兑换或管理，不接收用户书籍、封面、阅读数据或同步快照。

所有档均不提供官方云存储或官方云同步；实际跨端传输由客户端直连用户自备 S3 / WebDAV。官方云、额度 / 用量、商品与购买账单目录、反馈截图上传和云清理模块均从活动服务移除，不保留返回空列表或零配额的兼容接口。本文描述新服务边界，不表示客户端联调或线上部署已经完成。

**当前发布的客户端版本尚未启用本页的账号与权益门槛**：注册暂未上线，自备 S3 / WebDAV 跨端同步无需登录或权益校验，全部功能免费使用。以下账号、试用与买断模型为账号服务上线后的规划；客户端开关位于 `src/Libzora.Core/AccountAvailability.cs`。

桌面端左侧的“登录 / 注册”和移动端“我的 → 登录 / 注册”支持选择**中国区 / 国际区**；当前注册入口提示暂未上线，账号服务部署后开放。
每个区域分别记住服务地址和登录会话。两区的账号数据库、会话、功能权益、本地书库和自备存储同步命名空间独立；相同用户名
可以在两区分别注册，另一地区的令牌不能用于本区登录或权益验证。

注册成功后直接登录。用户名为 3–32 位字母、数字、点、下划线或连字符，不区分大小写；
注册必须填写邮箱、用户名、登录密码及确认登录密码，两次密码必须一致；之后可以使用用户名
或邮箱登录同一个账号。用户名和邮箱在各自区域内不区分大小写且唯一；已有账号可以保留
原来的空邮箱，继续使用用户名登录。密码为 8–128 位，区分大小写。
登录后可用注册邮箱接收 8 位验证码完成邮箱验证；忘记密码时可向注册邮箱发送验证码重置密码。
验证码 15 分钟内有效、最多尝试 5 次，同一账号 1 小时内最多发送 3 封且 60 秒内不重发。
重置密码会撤销该账号的全部会话和设备登录，需使用新密码重新登录。未配置邮件服务时，
邮箱验证和密码找回提示邮件服务暂不可用；暂不提供第三方登录。

独立正式服务默认限制同一 IPv4 地址在滚动 24 小时注册 3 个账号、30 天 10 个账号，
IPv6 按 `/64` 网段合并计数。来源记录持久化，账号停用或重启不释放名额；并发注册在数据库锁内检查，
只统计成功注册，30 天后定期清理。超限返回 `429 registration_limit_reached`。
来源只取连接及明确可信代理；生产未配置可信代理时不采纳任何转发头。

后台 `/admin/registration` 支持 IP / CIDR 网段、邮箱、用户名黑名单及到期、查询、解除。
管理员封禁自动限制该邮箱和用户名再次注册，账号停用后仍保留限制；受限用户名也不能通过修改取得。
解封只解除该账号封禁产生的规则，手动规则须单独解除。IP 黑名单仅限制新注册，不阻止正常用户登录。
用户名或注册信息受限时客户端显示明确提示。邮箱在注册时验证格式和唯一性，登录后可通过验证码验证所有权；生产仍建议配合机器人验证。

账户中心的“账号资料与安全”支持修改用户名及密码，操作前需要输入当前密码。注册邮箱
只读，不支持修改或清空；邮箱旁显示验证状态，可发送验证码完成验证。服务端先检测重复用户名，并以数据库唯一约束防止并发重名；改名保留原账号、会员、
设备记录；自备存储和本地书库不由账号服务管理。修改密码后轮换本机登录会话、撤销其他设备会话，本机继续登录。

自助“注销”改为**账号停用**：须输入当前密码并手动输入确认文字，确认后停用账号、撤销全部会话，阻止该账号继续登录和验证付费同步权益。确认文字和客户端界面以联调后的实际版本为准。

账号停用不是服务器数据删除。服务保留必要许可及审计记录，不能声称服务器数据已销毁。本地书库和用户自备 S3 / WebDAV 数据均保留；停用不会清理书籍或重写历史权益账本。历史已用码仅按下文的必要只读兼容保留，不恢复兑换。

### 试用与到期

试用为 **7 天、每账号一次**，必须由用户在账号中心主动领取，不随注册或登录自动发放。重复或并发领取不得延长或重复发放同一账号的试用。领取状态由账号服务管理，不能通过切换设备重新领取。

试用过期只停用付费同步功能，Free 的本地阅读、书库、USB Kindle、插件及自配 AI 继续可用。**不删除用户自备存储中的数据，也不删除本地书库。** 已购 Lifetime 永久权益不受试用结束影响。自备服务的存储保留和账单由用户及其服务商负责，不存在 Libzora 官方云空间到期保留或销毁规则。

历史已付限时权益按原到期时间继续有效，不因本次调整自动转为永久，也不重新发放试用；其只读兼容边界见下文。

### 买断开通与账号中心

买断订阅沿用 **¥88 永久**，无需续费；7 天试用规则同样沿用。买断权益直接绑定对应区域的账号，永久权益由受保护的管理员操作按外部授权开通。**购买和开通方式以实际渠道公告为准；开通后刷新权益。** 本文不表示购买渠道、自动支付或支付网关已上线。账号服务不处理产品、订单、支付或购买账单，也不提供激活码生成、兑换或管理；客户端不能自行授予权益。

账户中心嵌入桌面主窗口右侧功能区，由左侧账户入口或同步设置的账户入口进入，保持导航可用。摘要只展示账号、权益、试用与设备，不展示官方云容量、下载额度、购买订单或激活码入口。客户端开通后只刷新权益，并在使用付费同步时实时验证。离开账户页清空密码；账号停用仍要求手动输入确认文字和当前密码。

所有账号最多同时登录 **6 台设备**。账号页显示本账户已登录设备、当前设备、最近访问，
可踢出设备以释放名额；被踢设备的服务端会话立即失效。管理员还能停用设备，阻止重新登录。
客户端后台每 **24 小时**检查一次，成功时间跨重启保留；网络失败保留登录并重试，失效后
清除对应区域会话并提示重新登录。登录、手动刷新和付费同步功能使用仍实时验证权限。
设备身份为平台密钥库保护的随机 ID，不使用硬件序列号；身份、会话、检查时间和会员状态
不进入备份或云同步，导入备份不会占用原设备身份。

必要的后台权益管理只允许受保护管理员按外部授权为对应区域账号开通或撤销权益，操作须管理员认证、CSRF、操作原因及审计。客户端只领取一次试用、刷新账号权益并实时验证功能，不通过请求自行开通永久权益。

权益直接绑定账号，不生成、发放、查看、导出或兑换激活码，不提供相关接口或后台目录。已撤销或到期权益不会因客户端刷新而恢复；账号停用后仍保留必要许可账本与审计，历史记录仅用于只读兼容。

## 独立服务器与配置边界

用户管理服务位于独立项目 `~/Desktop/Libzora_server`，使用 ASP.NET Core / .NET 10、PostgreSQL 和管理网页，不依赖客户端源码路径。配置与部署资料以该项目 README 及[客户端部署入口](account-server-deployment.md)为准；本文只说明配置边界，不承诺任何未经验证的线上账号或权益迁移。

本机两区身份服务的入口保持独立：

| 区域 | 客户端服务地址 | 管理网页 | 账号数据库 |
| --- | --- | --- | --- |
| 中国区 | `http://127.0.0.1:5088` | `http://127.0.0.1:5088/admin` | PostgreSQL `libzora_china` |
| 国际区 | `http://127.0.0.1:5089` | `http://127.0.0.1:5089/admin` | PostgreSQL `libzora_international` |

两区数据库、数据库账号、管理员会话、数据卷和备份不得共用。初始本机管理员的随机密码只保存在被忽略且仅本机用户可读的 `.local/local-config.json`，不写入源码或日志。已有 `demo_cn_` 演示账号与本机数据应保留，不能为了更新方案清空。

账号数据库仅用于必要的身份、会话哈希、功能权益、设备、试用及许可 / 安全管理审计，不建立产品、支付或订单目录，不承担用户书籍或同步快照的存储、索引或计量。账号服务不配置官方书籍或反馈截图对象桶，不签发书籍上传或下载链接，也不持有用户的自备存储凭据或同步密钥。真实数据库、旧账本、历史已用码和云文件不因精简活动服务而迁移或删除；历史记录仅必要只读兼容，不恢复码兑换。

`GET /health` 返回服务标识 `libzora-accounts`、区域（China 为 0，International 为 1）和 `administration: true`。数据库初始化的区域标记禁止跨区复用。macOS、移动端预览和 iOS 模拟器的回环地址为 `127.0.0.1`；Android 模拟器开发机地址为 `10.0.2.2`，真机使用可访问的 HTTPS 服务。

## 自备存储、加密与兼容

在所选区域账号具有有效 Trial 或 Lifetime 权益后，选择自备 **S3 / WebDAV**，保存连接信息并设置同步密钥。书籍、批注、书签和阅读记录按现有快照协议合并；书籍可按需下载，也可开启同步时下载完整书籍。文件传输直连用户自己的存储；账号服务只验证身份及功能权益。

同步密钥仅在用户设备本地保存，不上传账号服务、不进入普通备份。用户须自行保管；遗忘后不能解密已有自备存储数据或 `.libzora` 加密备份，账号密码重置不能找回同步密钥。完整数据备份也必须使用已配置的密钥，详见[加密备份说明](backup-encryption.md)。

新加密书籍与封面使用 `objects/encrypted/<64位命名空间>/<64位不透明名字>`。对象名为密钥派生的 HMAC，而非明文文件哈希；路径不包含口令摘要。自备加密 S3 / WebDAV 的随机命名盐保存在**加密快照**的 `BlobNamingSalts`，不上传公开口令摘要或独立盐配置文件。多设备产生不同盐时合并保留全部命名空间，读取、去重和清理兼顾所有保留盐。未设置密钥的自备存储仍使用明文 `objects/plain/<SHA-256>`，不承诺隐藏文件指纹。

新加密书籍与封面使用 `LIBZORA-SYNC3`，真实长度位于认证密文内，按 Padmé 分档向上补齐。快照仍使用 `LIBZORA-SYNC1`。自备存储服务仍能看到对象数量、大致大小、传输时间和同步频率，不能宣称消除了全部元数据泄露。命名密钥按 PBKDF2-SHA256（120,000 次）及独立用途标签派生；完整格式与校验要求见[快照兼容约定](s3-snapshot-compatibility.md)。

同步写入与最低读取协议均为 **6**，参与设备须一起升级。新客户端继续兼容读取旧快照及 `SYNC1` / `SYNC2` 对象；不向旧目录写入，也不自动删除旧对象。旧名称暴露的哈希不能被追溯隐藏。确认新文件和备份可解密后，再由用户自行清理原目录；更换密钥须使用新的同步前缀。

## 客户端区域隔离

中国区沿用已有安装根目录下的书库；国际区使用 `<安装根目录>/regions/international/`。
数据库、阅读记录、同步配置、设备 ID、同步基线和备份目录分别保存。切换区域后可以立即
注册、登录或退出该区域账号；界面提示重新打开应用，以加载对应区域的独立书库。
重新打开前，当前进程禁止同步和按需下载，包括后台同步，避免向另一地区发送现有书库。
切回原区域并重新打开后，原来的本地书库和登录状态仍保留。

身份与权益验证绑定当前区域、服务地址、账号和设备会话；更换账号、地址、退出或会话失效后，旧会话不能继续用于验证付费同步。登录或刷新账户中心不应覆盖用户保存的自备 S3 / WebDAV 选择。

应用中的 S3 / WebDAV 同样使用区域命名空间：`regions/china/<目录前缀>/` 和
`regions/international/<目录前缀>/`。即使填写相同 Bucket 或 WebDAV 地址，两个区域也不会
合并数据。已有未分区的远端 `<目录前缀>/` 数据不会自动迁入，新版首次同步使用分区目录；
原有本地书库会上传到当前区域。每个区域独立保存连接凭据。连接参数文件仍只支持 S3 / WebDAV；
账号会话不能导出。普通备份不包含账号会话，恢复备份不会恢复账号权益会话或自动启用跨端同步。

## 服务器配置

独立服务器需要 .NET 10 ASP.NET Core Runtime 和 PostgreSQL。正式环境将两区服务运行在各自区域的主机上，
使用独立的数据卷、备份和 HTTPS 域名。网关按域名固定代理对应区域，不配置跨区回退、
账号或权益复制；自备同步数据仍按客户端区域前缀隔离。客户端两区默认地址集中在
`src/Libzora.Core/AccountServerEndpoints.cs`，支持 `LIBZORA_ACCOUNT_SERVER_CHINA` /
`LIBZORA_ACCOUNT_SERVER_INTERNATIONAL` 环境变量覆盖；已登录令牌仍绑定原服务器。
完整字段、已安装客户端的默认地址更新和部署注意事项见[部署配置入口](account-server-deployment.md)。

服务仅开放权益验证所需的身份、邮箱恢复、区域、6 台设备 / 会话、试用、功能验证 / 到期、账号停用，以及受保护后台权益开通 / 撤销 / 审计接口。官方书籍 `/api/sync/`、`/sync-blobs/`、商品 / 订单、码生成 / 兑换 / 管理、反馈上传及云清理不再属于活动服务；不是关闭开关、返回空目录或返回零额度。代理、运行用户、数据目录与日志仍须遵守最小权限；上线前核验移除的路由不可用，但不得删除真实数据库、旧账本、历史已用码或云文件。用户自备 S3 / WebDAV 凭据不属于账号服务端配置。

公网账号服务及自备存储连接使用 HTTPS，客户端拒绝账号请求重定向；回环开发地址及 Android 开发机别名除外。可信代理须通过 `Server__KnownProxies__0` 等明确配置，不信任任意转发头。数据库连接信息由私有部署环境提供，专用运行用户仅可读写自己的区域目录。

## API 与会话

下表仅列必要账号与功能权益验证的协议入口。会员对象只包含 `accountId`、`region`、`tier`、`hasLifetimeFeatures`、`featureExpiresAt`、`deviceLimit`、`loggedInDeviceCount`、`activatedDeviceCount`、`trialAvailable`、`trialClaimed`、`trialClaimedAt`、`trialExpiresAt`。不再输出官方云、容量、用量或下载额度字段，也不以零配额维持旧响应。

不再提供激活码生成、兑换、管理接口或兑换响应协议。买断开通后客户端只刷新会员 / 设备状态，并实时校验功能权益；永久权益开通和撤销只允许受保护管理员操作。历史档位仅在下文的历史只读兼容说明中保留，不能作为当前输出。

不能单凭 `hasLifetimeFeatures` 的字段名称把历史限时许可解释为永久；历史已付限时权益仍须结合 `featureExpiresAt` 按原到期时间验证。以上响应约定及账号停用须在客户端与独立服务端联调中核验，不表示线上部署已完成。

所有账号请求必须携带 `X-Libzora-Region: china` 或 `international`，并与服务的固定
区域相同，否则返回 403。认证 JSON 中的 `region` 同样必须匹配。区域标签由服务器配置
决定；请求头用于防止误连，不能改变服务器区域。

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| POST | `/api/accounts/register` | JSON 必填 `email`、`username`、`password`、`confirmPassword`，以及 `region`、`deviceId`、`deviceName`、`platform`；校验邮箱格式、用户名与邮箱唯一性和两次密码一致后创建账号并返回会话 |
| POST | `/api/accounts/login` | JSON `username` 可填写用户名或邮箱，还需 `password`、`region`、`deviceId`、`deviceName`、`platform`；验证后返回会话 |
| GET | `/api/accounts/session` | `Authorization: Bearer <SESSION_TOKEN>`；验证设备会话、更新最近访问，不延长到期时间 |
| POST | `/api/accounts/logout` | 同一认证头；撤销当前会话，返回 204 |
| POST | `/api/accounts/password-reset/request` | 匿名；JSON `username`（用户名或注册邮箱）；已知账号且邮件服务可用时发送 8 位验证码，未知账号同样返回 202 但不发信 |
| POST | `/api/accounts/password-reset/confirm` | 匿名；JSON `username`、`code`、`newPassword`、`confirmPassword`；成功后撤销全部会话并标记邮箱已验证，返回 `user` |
| POST | `/api/accounts/email/verify/request` | 认证头；向注册邮箱发送 8 位验证码；未设置邮箱返回 `409 email_not_set` |
| POST | `/api/accounts/email/verify` | 认证头；JSON `code`；成功后返回 `user`（含 `emailVerified: true`） |
| POST | `/api/accounts/trial` | 必须登录，由用户主动领取一次 7 天 Trial；重复或并发领取不延长、不重复发放，权益按服务端时间到期 |
| GET | `/api/accounts/membership` | 当前账号功能权益、试用状态与设备数量 |
| GET | `/api/accounts/devices` | 当前账号设备列表 |
| GET | `/api/accounts/devices/<DEVICE_ID>` | 验证当前会话绑定的设备，返回会员与设备状态 |
| POST | `/api/accounts/devices/<DEVICE_ID>/features` | 验证当前设备的功能权益 |
| POST | `/api/accounts/devices/<DEVICE_ID>/kick` | 踢出本账户的设备，立即撤销其会话 |

商品 / 订单 / 购买账单目录、反馈及截图上传接口和对应后台模块已从活动服务移除，不以空列表保留购买兼容。问题反馈可通过 [GitHub Issues](https://github.com/kingstacker/Libzora/issues) 提交，先检查日志和截图中的敏感内容；账号服务不上传或保存反馈截图。

账号服务的所有响应都带 `X-Libzora-Server-Time`（ISO 8601 UTC）。客户端用请求往返中点估算本机与服务器的时钟偏移，并限制在 ±30 天内，用于校准同步使用的混合逻辑时钟；这仅是时间参考，账号服务不接收、解析或解密快照内容。自建 S3/WebDAV 没有该响应头时，客户端退回本机时钟。同步时序规则见[扩展 S3 同步内容](s3-sync-extension.md)。

注册/登录返回 `region`、`user: { id, username, email, emailVerified }`、`token`、`expiresAt`，旧账号的 `email` 可为空。
错误密码和不存在的账号统一返回 401；重复注册返回 409；同一来源每分钟最多 10 次
注册/登录，超过后返回 429。认证请求体最多 16 KiB。

独立服务另有持久化成功注册数量限制；注册超限返回 `429 registration_limit_reached`，
命中黑名单返回 `403 registration_blocked`，改为受限用户名返回 `403 username_blocked`。

第七台设备返回 `409 device_limit_reached`；被管理员停用的设备无法登录。自定义功能无权益时
返回 `402 membership_required`。本机测试限速放宽至每分钟
1,000 次，正式默认仍为 10 次。

密码使用随机盐和 PBKDF2-SHA256（600,000 次迭代），数据库不保存原始密码。会话使用
32 字节随机令牌，有效期 30 天；服务器只保存令牌的 SHA-256 哈希。账号和会话在服务重启
后保留。退出仅撤销当前设备、当前区域的会话，不影响其他设备或另一地区账号。
客户端通过平台 `ISecretProtector` 独立加密两区会话，不保存账号密码；会话不进入任何云同步
或 `.libzora` 备份。服务器不可用时仍可在本机退出，界面提示远端撤销尚未完成。


## 历史只读兼容（不属于当前输出或活动服务）

旧 Plus 档位 `pro` 仅供历史记录只读识别，不再发行或在会员 JSON 中输出。历史已付限时权益按原到期时间继续验证有效性，不自动转换为永久、不续发旧档位，也不恢复已撤销权益。

旧账本、历史已用码、真实数据库及云文件原样保留，不为本次精简迁移、删除或执行云清理。历史已用码与账本仅用于必要只读兼容，不生成新码、不恢复兑换，也不将历史权益重新开通或自动转为永久。保留这些记录不意味着继续开放旧商品 / 订单目录、官方云传输、配额 / 用量或反馈截图接口。

历史加密对象格式仅保留读取兼容，详见[快照兼容约定](s3-snapshot-compatibility.md)；不保证历史官方云服务可访问，不承诺自动迁入自备存储。客户端仓库的 SQLite 协议测试服务及旧 PostgreSQL / iOS 测试记录不能证明新服务边界已部署或完成联调；应另外核验主动试用、原到期权益、受保护后台开通 / 撤销、账号停用、自备同步及区域隔离。

## 阅读周期

阅读数据按钮为“周 / 月 / 年”，默认选中周。本周从周一开始；本月按实际天数显示；
今年按 12 个月汇总，包含闰年的 2 月 29 日。未来日期显示为空，不计入时长。统计沿用现有
阅读记录的 UTC 日期；切换周期不改变累计时长、近七天日均、最近阅读和勋章数据。
