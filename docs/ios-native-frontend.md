# iOS 原生前端

从 2026-11-07 起，iOS 项目默认使用 **Swift + SwiftUI** 界面。
`UseSwiftUIFrontend=true` 由 `Libzora.Mobile.iOS.csproj` 设置。
Android 继续使用共享的 Avalonia 界面。

## 界面与业务的分工

SwiftUI 负责四个标签页、导航、列表/网格、滚动、输入框、按钮、开关、分段选择器、
滑块和弹窗。阅读设置的开关通过 `UIViewRepresentable` 使用独立的 UIKit `UISwitch`，
其尺寸和 Accessibility 范围跟随实际控件。系统文件选择器、分享面板、确认框由 UIKit 显示。
`IOSNativeSceneDelegate` 在窗口显示前创建 SwiftUI 根页面。
UIKit 恢复旧版 Avalonia 的场景会话时，`AppDelegate` 会在激活时补建原生窗口，
不删除书库或设置、不要求卸载重装。

启动时显示「Libzora」和「为学日益，为道日损。」的淡入动画，并等待约 2 秒；期间并行获取
真实书库快照，按保存的视图与排序预解码首屏封面。等待结束且书库准备完成后显示首页，
加载较慢时继续显示加载状态。从阅读界面退出后再次启动，会跳过品牌动画和 2 秒等待，
直接恢复上次阅读；空库正常进入导入入口；
首次加载失败或请求超时会显示可重试的错误，避免一直停在开屏。
启动恢复阅读和 `--libzora-disable-restore` 仍沿用原有行为。

`NativeTheme.swift` 复用原有 `MobileTokens.axaml` / `MobileTheme.axaml` 的视觉规则：
京华老宋界面字体、24 点页边距、轻灰按钮、6 点封面圆角和 16 点浮动工具栏。
普通文本、导航栏标题与按钮、分段控件标题和底部标签都使用该字体；系统确认框保持系统字体。
四个标签页的抬头共用 `NativeTheme.pageTitleFont`，字号和字形保持一致；
书库、阅读资料、阅读数据、我的不再各自设置标题大小。
`NativeBookshelf.swift` 保留紧凑的书库标题、三列书架、细进度条和收藏夹封面卡片；
“收藏夹视图”与网格视图、列表视图放在同一组，均可通过显示菜单切换。
详情页使用居中封面和底部固定的阅读按钮。“我的”和阅读资料保持自定义页面布局。
书库封面下不显示单书阅读进度条，标题与封面保持紧凑间距。
书库和收藏夹中的封面或列表行轻点直接阅读；长按书卡或列表文字时，应用自己的预览层
把整张书卡（封面、书名和作者）以书卡中心为缩放中心放大约 1.1 倍，书名、作者与封面
保持原有换行和相对大小。预览只有书卡内容，不画系统预览的白色底板、圆角卡片或遮罩弧形，
原位置书卡在预览打开期间隐藏。预览层位于底部标签栏之上，靠近底栏的书卡也不会被标签栏
盖住；点按预览外的区域收起预览。操作菜单为 iOS 26 液态玻璃面板（旧系统回退到半透明
材质），不画分隔线，在书卡下方展开，空间不足时移到书卡上方，“书籍详情”进入详情及编辑页面。
显示选项提供网格视图、列表视图、收藏夹视图和排序；画廊模式在“我的”中的书库设置里启用。
画廊模式在网格和收藏夹中隐藏标题、作者与进度并收紧行距；书库设置还可开启书籍同步状态图标。
同步图标默认关闭，开启后按本机最近的同步基线显示未同步、已同步或待下载，
不查询云端实时状态；偏好会随其他界面设置一起保存。
书库设置还提供默认关闭的炫彩模式：按封面色相合并明暗色块，以面积为主选择代表色，
排除占比不足 6% 的彩色细节，避免小标题或角标主导背景。彩色取样保留封面色相并适度提亮；
黑白封面只留下很淡的底色，不把整页染灰。
可见封面按三列三行的屏幕区域分组，九个固定渐变位置优先使用附近且露出较多的封面颜色，
避免仅由最前面几本书决定整页背景，也不混合互补色而产生灰色。
滚动、搜索和筛选时更新区域配色，封面解码合并 120ms 内的变化，颜色以 0.8 秒柔和过渡；
区域变化只更新颜色，不移动渐变位置。初次使用最近更新书籍的配色回退。
阅读资料、阅读数据、我的及后续打开的页面共用这套配色。无可用封面时使用普通背景。
阅读纸张选择“跟随”时，跟随应用明暗和炫彩，正文、上下留白与底部进度栏使用同一连续叠层；
手动选择白、米、黑纸张时，统一使用所选纯色，不叠加炫彩。
书库浮动标题栏使用向下延伸的分段渐隐遮罩，回到顶部时与相同尺寸的原位标题栏衔接，
回滑接近顶部时不会在距离顶部 64 点处提前关闭；遮罩透明度随接近顶部逐渐降低。
继续向后浏览书籍时，浮动栏按滚动方向自动收起，搜索状态也不会强制固定工具栏。
滚动方向仅按内容高度与视口限定的有效偏移计算，顶部和底部越界回弹不会触发标题栏。
选中文字工具栏跟随选区位置，上方空间不足时显示在下方；选区铺满页面时优先放在顶部。
图标顺序与电脑端一致：复制、划线、笔记、搜索、词典、AI、翻译、朗读；朗读只读所选文字。
目录采用紧凑普通列表，移除顶部默认分组留白；右上角的单个系统玻璃按钮切换
全部子目录的展开和收起，并保留父章节旁的独立折叠箭头。点击章节标题仍直接跳转阅读。
目录列表、导航栏和弹层底色统一使用当前阅读纸张；“跟随”模式继续使用阅读器的炫彩配色。
原生交互不需要改成系统大标题或分组设置页的默认外观。
高级筛选使用独立的卡片式页面：顶部返回、标题和右上角“清除”，阅读状态与格式为胶囊选项，
作者、标签和分类进入可搜索的选择页；底部“查看 N 本书”按当前草稿、快捷筛选和搜索
计算数量，关闭或返回不会改动书库，只有确认后才应用并重新请求筛选结果。
iOS 26 起筛选卡片和按钮使用系统玻璃材质，导航按钮使用系统工具栏；旧系统使用回退样式。

展开收藏夹后使用与书库相同的 `NativeBookShelf`、封面尺寸、书名/作者字体和进度条，
两处也共用网格/列表偏好与排序。收藏夹添加、长按移出、清空、合并和解散继续走原有业务。
阅读页的搜索复用书库的 `NativeSearchField`，在顶部放大镜左侧展开；提交后，
结果显示在工具栏下方的紧凑浮层。搜索框保持在当前工具栏中，结果不再另开搜索页面。

阅读设置使用系统紧凑底部弹层，保留原生拖动指示器、圆角和滚动行为。
上下阅读工具栏左右各留 8 点，与 iPhone 系统排版弹层的边界对齐。
高度最多 340 点（PDF 为 220 点），并随可用高度缩小；设置可滚动，正文保持实时预览。
行距按紧凑、标准、宽松提供 1.5、1.75、2.1 倍行高，移动端正文优先使用用户设置。
段间距采用 0、0.5、1 个字号的额外留白，替代相邻正文段落的书内间距，不影响段内行距。
间距设置会保存，改变时正常连续分页并更新页数缓存，保留当前文字可见；
不强制把原页首另起一页，也不因段落必须保留两行而提前换页；手机端按剩余行数续排。
竖排点击左侧前进、右侧返回，右滑前进、左滑返回，翻页动画方向同步反转。

iOS 主图标与 macOS 共用 `scripts/macos/Libzora.icon` 的 Icon Composer 图层，
由 ACTool 生成 `Libzora` 图标栈及浅色、深色、着色外观。iOS 26 使用分层液态玻璃图标，
旧系统使用同源生成的平面回退图标。各平台“关于”均已移除咖啡支持入口及二维码弹层。

C# 的 `ApplicationModules` 继续负责书库、SQLite、阅读记录、同步、AI、词典、
Kindle 邮箱和备份。数据目录、书籍文件、同步协议和已有设置文件保持兼容。
Swift 与 C# 通过同一进程内的 C ABI 传递 JSON 请求、结果和状态事件，不运行本地服务器。
`IOSNativeJsonContext` 提供显式生成的 JSON 元数据，桥接序列化不依赖运行时反射。

阅读正文继续使用现有的 EPUB 排版器和 PDFium。`ReaderPage.UseNativeFrontend()`
隐藏 Avalonia 的阅读工具栏、弹窗、选择菜单等界面，只向 SwiftUI 输出状态和操作。
单独的 `AvaloniaView` 作为 SwiftUI 阅读页的子控制器显示；它不承担窗口导航。
长按选字、翻页、进度保存和内容定位仍由共享阅读器处理。
正文图片仅在完整点击后打开全屏查看器，滑动、翻页或移出后返回原点不会触发打开。
图片与表格查看器支持双指缩放、双击放大和横屏；iPhone 关闭查看器后恢复竖屏，
保留阅读位置，iPad 继续支持原有四个方向。

这一边界可以避免将 UIKit 按钮叠在整棵 Avalonia 场景之上时，按钮位置、滚动裁剪、
弹窗遮挡和键盘焦点需要分别同步的问题。所有可操作控件现在处于原生页面层级中。

## 已接入的页面和操作

- 书库：网格/列表、搜索、筛选、排序、继续阅读、文件导入和 TXT 规则预览。
- 书籍：详情、编辑信息/封面、修改书名、收藏、加入收藏夹、回收站和发送到 Kindle。
- 收藏夹：创建、重命名、添加/移出书籍、清空、合并和解散。
- 阅读资料与统计：书签/划线/笔记、按位置打开、导出、阅读时长、每日数据和勋章。
- 我的：外观、S3/WebDAV 同步、参数导入/导出、AI、邮箱、备份、回收站、词典、关于和问题反馈。
- 阅读器：原生工具栏、进度、目录、正文搜索、排版/PDF 缩放、朗读、批注、词典、翻译和 AI。

同步继续使用 `MobileSync` 的并发控制和删除确认流程；备份/恢复继续使用
`MobileDataCoordinator` 的数据操作屏障。恢复完成后会阻止继续操作并提示重启。
用户账号与同步设置的登录、退出、保存和立即同步按钮位于列表内容末尾，随页面滚动，
不再固定在底部安全区；登录状态切换后账号页回到顶部，显示用户名和会员状态。
同步仅支持用户自备 S3 / WebDAV。登录或刷新会员权益不会创建官方云连接，也不会覆盖
已保存的自备连接和密钥；旧官方配置会关闭，确认自备目标并保存后才可恢复同步。
“我的 → 关于 → 问题反馈”打开原生支持说明页，无登录门槛、正文表单、截图选择、日志附加或
提交操作。用户可主动打开外部公开的 GitHub Issues，应用不会自动打开、附加或上传内容。

会员只展示 Free、试用订阅和买断订阅：Free 保留本地阅读、书库、自配 AI 与本地加密备份；
用户主动领取一次固定 7 天试用，试用与买断均只解锁自备 S3 / WebDAV 同步。
买断权益直接绑定账号，由受保护的服务端管理员依据合法授权开通，客户端仅刷新和实时验证；
无激活码、商品目录、购买订单或支付命令，不宣称真实购买渠道已接入。
试用到期只停用同步权益，不删除本地书库或自备存储数据；历史有效限时权益保持原到期时间。

登录后的账号页显示头像、用户名、区域、会员徽标与有效期，以及刷新、退出和设备管理。
已登录设备按当前设备优先、最近活跃排序，显示名额、平台、活跃时间与“退出此设备”操作；
没有官方云空间或流量统计卡。登录与注册信息位于页面顶部，区域仅在未登录表单中切换。
账号页保留注册邮箱验证和忘记密码，通过 8 位邮箱验证码验证或恢复账号；
限时权益到期前 30、7、1 天的提醒以账号页横幅显示，永久权益无到期提醒。
会员方案标注当前区域，两区域账号、权益和会话保持独立，客户端不能自行授予或跨区转移权益。
书签的章节路径、fragment 和 `ReaderContentPosition` 会完整传过原生桥接层。
关闭阅读会取消当前阅读会话的搜索、AI 和翻译请求。
界面偏好在点击时立即更新，再异步保存；请求版本检查避免旧回复覆盖新的选择。
原生开关的 Accessibility 标识位于开关自身，滚动后不会把标签所在的整行当成开关点击区。
工具栏搜索提交、关闭和重新搜索会取消过期请求；每次查询使用独立标识，旧请求只能取消自身，
旧结果不会回写当前搜索。EPUB 先展示当前可见页的匹配，再在后台搜索当前章，随后每 10 章
推进后续章节及书中前面的章节。缺失索引按章保存，取消后保留已完成章节；下次查询继续建立。
结果边搜边显示并可直接跳转，同段多次出现分别列出，重叠索引片段按实际位置去重，最多显示
200 条。扫描和数据库访问不占用阅读导航锁，后台任务持有数据操作租约直至退出。
目录的层级关系和可见条目仅在加载或折叠状态变化时重建，避免滚动时反复遍历整个目录。

阅读页四周的 SwiftUI 留白使用与 `ReaderPalette` 相同的纸张颜色（白、米、绿、黑），
正文上下不出现色带。选中文字后点击正文只取消选择，不翻页，也不打开工具栏。
目录打开时标记并滚动到当前章节，面板标题显示书名；插图等没有独立目录项的页面
归属前一个目录项。
阅读资料中的 EPUB 划线和笔记显示日期，导出仍写入章节路径或页码。
阅读页的提示显示在当前工具栏上方，不遮挡选择工具栏。

「排版 → 底部进度」可选择页码、章节或剩余时间，切换即时生效并保存在
移动端偏好中；旧版本保存的「本章剩余」会在加载时升级为剩余时间。章节按目录
条目计数（与目录面板一致），名称和全书百分比仍显示在底部。页码是整本书的
页码：当前章节使用实际分页数，其余章节先按章节文件大小估算，约两秒后由后台
精确分页替换，打开大部头不会阻塞首屏。大章节优先排到恢复位置之后约 8000 字，再后台补全；
补全前以文本位置显示进度，依赖完整分页的跳转、跨章回翻和朗读会等待目标章排版完成。
无文本位置的旧阅读记录仍先完整排版，以保留原有恢复精度。剩余时间用该书累计阅读时长与进度学习
阅读速度，至少积累 2 分钟且进度超过 1% 后才显示时间，学习期间显示「阅读速度
估计中」。PDF 没有目录时，章节模式显示页码。朗读控制条无操作 4 秒后自动收至
右侧，点按可展开，暂停和继续会重新计时；打开朗读设置或搜索结果时暂停收边计时。

「排版 → 正文字体」列出内置京华老宋体、CoreText 提供的系统字体（苹方、宋体、
楷体等，只保留包含常用简体汉字的字面）和可下载字体（思源宋体、霞鹜文楷、
朱雀仿宋、思源黑体，均为 SIL OFL 1.1）。系统字体的字节由
`SKTypeface.OpenStream()` 在内存中交给 HarfBuzz，不读取系统字体目录。下载目录
定义在 `ReaderFontCatalog`：Debug 构建把 `src/Libzora.App/Assets/Fonts/catalog`
打进应用包，Release 从 `RemoteBaseUrl` 下载并在安装前校验大小和 SHA-256。
偏好只保存稳定键（`system:<Family>` 或 `catalog:<id>`）；iOS 更新会改变应用容器
路径，所以绝对路径只存在于内存注册表，每次启动由 `FontLibraryService` 从清单重建。
切换字体会在新布局安装完成后释放上一款系统字体占用的内存（苹方 TTC 约 59 MB）；
如果后台排版或表格预览仍在合成，则等合成结束后释放，切换回来时再按需重新加载。

阅读状态、批注弹窗和 AI 流式文本由独立的 `NativeReaderSession` 发布，只有阅读页观察它。
翻页、朗读进度和 AI 输出不会让书库等标签页重新计算。书库刷新时只替换有变化的数据，
书库和阅读资料每次渲染只做一次筛选、排序或分组。

## 构建

需要 macOS、Xcode 命令行工具、仓库指定的 .NET SDK 和 iOS workload。
MSBuild 自动调用 `NativeUI/build-native-ui.sh`，按目标架构编译并链接 Swift 静态库。
最低系统版本为 iOS 15；iOS 26 的控件材质由系统提供。

Intel 模拟器 Debug：

```bash
dotnet build src/Libzora.Mobile.iOS/Libzora.Mobile.iOS.csproj \
  -c Debug -r iossimulator-x64 -p:UseSharedCompilation=false
```

Apple Silicon 将 RID 改成 `iossimulator-arm64`。

模拟器产物：

```text
src/Libzora.Mobile.iOS/bin/Debug/net10.0-ios/iossimulator-x64/Libzora.Mobile.iOS.app
```
