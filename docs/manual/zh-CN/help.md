# 常见问题

## 导入后找不到书

先确认左侧选中的是“电脑书库”，不是“设备书库”。清除搜索词和格式筛选，再按书名、作者搜索。导入同名文件时若选择“跳过”，本次文件不会加入书库；也可以检查书籍详情中是否作为另一种格式添加。

## TXT 章节目录不正确

TXT 导入会识别常见编码、章节标题和分卷标题。若目录未正确生成，先用文本编辑器确认章节标题单独成行，并检查编号、标点和卷标题是否统一。重新导入前可删除错误的导入记录；原始 TXT 文件不会因导入而被改写。

## 书籍打不开或封面空白

确认文件没有 DRM，且文件本身没有损坏。AZW3 阅读仅支持无 DRM 文件。封面读取失败时，可以在书籍详情里重新匹配或导入封面。格式转换需要安装 Calibre，并在“设置 → 书库与导入”确认 `ebook-convert` 可用。

## Kindle 没有出现在设备书库

1. 解锁 Kindle，并在设备上选择 USB 文件传输模式。
2. 确认数据线支持传输数据，不只是充电；换一个 USB 端口再试。
3. 暂时只连接一台阅读设备，再等待 Libzora 检测。
4. 查看“设置 → 高级与集成”里的 Kindle 平台诊断，以及 Windows 是否能看到设备存储。

设备识别后再进入“设备书库”。如果系统和 Libzora 都看不到设备，先解决 USB/MTP 连接问题。

## 传书后 Kindle 里暂时看不到

先确认 Libzora 提示传输完成，再安全弹出设备。回到 Kindle 主屏刷新书库；部分设备需要重新启动或等待索引完成。若发送格式不受设备支持，先用 Calibre 转换为兼容格式。

## Send to Kindle 和 USB 传输有什么区别

USB 传输需要设备物理连接，文件直接写入设备；Send to Kindle 走 Amazon 在线服务，发送后还要等待 Kindle 联网同步。确认在线发送账号和目标设备无误后再发送。

## 扫描版 PDF 搜不到文字

扫描版 PDF 是页面图像，Libzora 当前不提供 OCR。可以缩放阅读、旋转页面和添加页面笔记；要搜索文字，先用外部 OCR 工具生成带文本层的 PDF。

## AI 连接失败

核对服务商的 API 地址、API Key、模型名称和账号权限，再检查网络功能是否开启。对 OpenAI 兼容接口，接口地址和路径按服务商说明填写；不要把 API Key 发到公开反馈中。

## Free、试用订阅和买断订阅有什么区别

**当前发布的版本全部功能免费：自备 S3 / WebDAV 跨端同步无需登录，账号注册暂未上线。** 以下为账号服务上线后的规划方案。

Free 包含完整本地阅读、书库、USB Kindle、插件和自配 AI。试用订阅（Trial）为 **7 天、每账号一次**，必须由用户在账号中心主动领取；买断订阅（Lifetime）为 **¥128 永久**，无需续费。Trial 有效期内和 Lifetime 均解锁自备 S3 / WebDAV 的跨端书籍、进度、书签和批注同步，每账号最多同时登录 **6 台设备**。

账号服务只做身份认证和功能权益管理，不接收用户书籍。存储与流量费用由用户承担；中国区与国际区的账号、权益、本地书库及同步数据不互通。

## 试用过期会删除我的书吗

不会。试用过期只停用付费同步功能，不删除用户自备存储中的数据，也不删除本地书库；Free 的本地功能继续可用。已经购买的 Lifetime 永久权益不受试用到期影响。自备服务的存储保留及收费政策由该服务商决定，Libzora 不代替用户管理存储账单。

## 如何开通买断权益

买断权益直接绑定账号，开通后刷新权益即可使用。当前版本尚未上线注册、购买或支付；入口开放后以实际渠道公告为准。

## “注销”会删除服务器和书库数据吗

注销账号需要验证当前密码并手动输入确认文字，完成后会退出登录并停止付费同步；本地书库、备份和自备存储中的数据不会删除。

## 自备存储同步只同步了封面，没有书籍文件

检查“同步时下载完整书籍”是否关闭。关闭时只同步元数据和封面；在另一台电脑打开书籍或点击下载图标后才拉取文件。

## 改了同步设置，立即同步仍使用旧配置

先点击“保存设置”，再点击“立即同步”。“测试连接”只检查当前填写的地址和凭据，不会保存设置。

## 如何恢复误删书籍

打开“设置 → 数据与同步 → 回收站”，选中书籍或格式并恢复。若已永久清理，只能从较早的 `.libzora` 备份恢复；恢复备份会覆盖当前书库。

## 仍然无法解决

在“设置 → 高级与集成”查看平台诊断并导出软件日志。向 [GitHub Issues](https://github.com/kingstacker/Libzora/issues) 反馈时，附上 Libzora 版本、操作系统、问题步骤和预期结果。不要公开 API Key、账号密码或未授权的书籍文件。
