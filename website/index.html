THE WHOLE READING DESK

从一本书开始，直到它真正被读完。

书库、阅读器、设备和阅读记录在同一处工作。没有多余的云端流程，也不打断你的阅读节奏。

01 LOCAL LIBRARY

把混乱的文件，变成真正的书库。

导入 EPUB、PDF、MOBI 和 AZW3，自动识别元数据与封面，按作者、标签、格式和阅读状态找到下一本书。

  • 拖放导入
  • 封面与元数据
  • 本地 SQLite

02 KREADER

让排版退后，让内容走到前面。

支持横排、竖排、滚动、分页和双栏阅读。书签、搜索、脚注、批注与阅读进度都围绕正文展开。

  • 原生排版
  • 竖排阅读
  • 笔记与批注

03 KINDLE WORKFLOW

从桌面书库，到手里的 Kindle。

连接 Kindle 后查看书籍、容量、字体和词典，批量发送、导出和安全退出设备，把传书变成一个清晰的动作。

  • USB / WPD / MTP
  • 字体与词典
  • 安全传输

04 READING TOOLS

读得更深，也记得更久。

用 AI 解释选文、总结章节或讨论全书；用批注、词典、阅读数据和导出记录，把阅读留下来。

  • AI 阅读助手
  • 词典查询
  • 阅读数据

BEFORE YOU START

下载前，先知道这几件事。

Libzora 支持哪些文件格式？

可以导入和阅读 EPUB、PDF、MOBI 与 AZW3。格式转换依赖用户自行安装的 Calibre。

我的书和 API Key 会上传吗？

书籍、封面、阅读记录默认保存在本机。账号服务只做身份和功能权益管理，不接收用户书籍；试用订阅与买断订阅的跨端同步直连你自备的 S3 / WebDAV。AI 请求只发送相关片段到你配置的服务，API Key 使用系统安全存储。

macOS 下载后如何打开？

请按照仓库中的 macOS 安装说明操作。发布包是否经过公证，以对应版本的发布说明为准。

在哪里反馈问题或查看更新？

可以在 GitHub 仓库提交 Issue，或者查看 Releases 和更新日志。

About Libzora

面向个人阅读的开源桌面工作台。

Libzora 是一款面向 Windows、Linux、macOS、Android 和 iOS 的开源电子书书库与 Kindle 管理工具。它将书库整理、阅读、批注和设备传输放在同一个本地优先的工作流中。
