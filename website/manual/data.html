备份与同步

Libzora 提供两种数据保护方式：本地 .libzora 加密备份适合手动迁移和离线保存；自备 S3 / WebDAV 同步适合多台设备之间持续同步。两者用途不同，建议在首次配置跨端同步前先导出一份本地备份。

权益与存储边界

当前发布的版本全部功能免费：自备 S3 / WebDAV 跨端同步无需登录或会员权益，账号注册暂未上线。 以下为账号服务上线后的规划方案。

Free 包含完整本地阅读、书库、USB Kindle、插件和自配 AI，本地备份也无需付费同步权益。试用订阅（Trial）/ 买断订阅（Lifetime） 解锁自备 S3 / WebDAV 的跨端书籍、阅读进度、书签和批注同步，每账号最多同时登录 6 台设备。试用为 7 天、每账号一次，由用户在账号中心主动领取，不自动开通；买断为 ¥128 永久，无需续费。

账号服务只做身份认证和功能权益管理，不接收用户书籍或快照；数据直接传输到用户自备的存储，存储与流量费用由用户承担。试用过期只停用付费同步功能，不删除自备存储数据或本地书库，已购 Lifetime 权益继续有效。

中国区和国际区的账号、权益、会话、本地书库、密钥和连接凭据分别保存。自备存储使用 regions/china/<目录前缀>/ 或 regions/international/<目录前缀>/；即使使用相同 Bucket 或 WebDAV 地址也不会合并两区数据。原来未分区的远端目录不会自动迁入。

买断权益直接绑定账号，开通后刷新权益即可使用。

注销账号需要验证当前密码并手动输入确认文字，完成后会退出登录并停止付费同步；本地备份、书库和自备存储中的数据不会删除。

导出本地备份

  1. 打开“设置 → 数据与同步 → 备份与恢复”。
  2. 先在同步设置中设置并保存同步密钥；设置或更改密钥需要输入两次，并在弹窗中确认。未设置时，导出会先提示设置，即使不启用跨端同步也需要密钥。再点击“导出备份”，在文件选择窗口中指定保存位置。
  3. 等待导出完成，确认 .libzora 文件出现在目标位置，再将它复制到外置磁盘或其他安全位置。

备份包中的书籍文件、封面、书库信息、阅读记录和回收站内容全部加密。它可以复制到另一台设备，但账号密码、账号会话、API Key、连接密码和同步密钥不会放入备份包。S3 / WebDAV 的敏感凭据需要从对应同步设置中单独导出，导出文件须按敏感文件保管。

可以开启“启动时自动备份（每日）”，并设置保留数量。Libzora 在距离上次备份超过约 20 小时时生成新备份；定期检查备份文件所在磁盘是否仍有足够空间。

导入备份或迁移到新电脑

  1. 在旧电脑先导出最新 .libzora 文件，并复制到新电脑。
  2. 在新电脑安装并启动 Libzora，打开“设置 → 数据与同步 → 备份与恢复”。
  3. 先设置导出备份时使用的原同步密钥，再点击“导入备份”，选择 .libzora 文件。
  4. 先关闭所有打开的阅读器，再确认导入。
  5. 等校验和导入完成后，完全关闭并重新打开应用，再检查书目、格式和阅读进度。

导入会覆盖当前书库。若目标电脑已有书籍或阅读记录，先从目标电脑另导出一份备份。API Key、邮箱密码和连接凭据需要重新配置，账号会话不会恢复。同步密钥由用户自行保管，不上传服务器，不提供找回；遗忘后无法解密旧备份或已加密的同步数据，账号密码重置也不能恢复密钥。 旧版明文备份不再接受导入。

配置 WebDAV

  1. 打开“设置 → 数据与同步 → 云端同步”，选择 WebDAV。
  2. 服务地址填写服务器上已经存在的目录，例如 https://dav.example.com/dav/；需要认证时填写用户名和密码/应用密码。
  3. 如果服务商要求自定义同步子目录，在高级选项中设置；默认目录名为 libzora。
  4. 点击“保存设置”，再点击“测试连接”。测试会验证读写能力并清理测试文件。
  5. 测试成功后点击“立即同步”。按钮会使用已经保存的配置；仅测试连接不会保存表单内容。

配置 S3 或兼容服务

  1. 在云端同步页选择 S3。
  2. 填写 Bucket、区域和 Access Key/Secret Key；使用 MinIO、Cloudflare R2 或其他兼容服务时，按服务商要求填写 Endpoint 和 Path-style 选项。
  3. 如需加密，设置本地加密密钥；设置或更改时需要输入两次并在弹窗中确认，在其他电脑上输入完全相同的密钥。
  4. 点击“保存设置”，运行连接测试，再点击“立即同步”。

访问密钥和本地加密密钥不包含在书库备份中。需要迁移连接信息时，使用 S3 设置中的独立连接参数导出，并把导出文件当作含有敏感凭据的文件保管。

多台设备保持一致

所有设备应选择相同的同步方式，并使用相同的 WebDAV 子目录或 S3 对象前缀。启用加密时，所有设备还必须使用相同密钥。忘记密钥后，已加密的云端数据无法恢复。 更换密钥或启停加密时，先改用新的同步子目录/对象前缀，再在其他设备配置同一套新参数。

可设置启动时、退出时或定时同步。关闭“同步时下载完整书籍”后，只同步书籍元数据和封面；在另一台电脑打开书籍或点击下载图标时再获取书籍文件。书卡同步状态图标可提示未同步、已同步或待下载状态。
