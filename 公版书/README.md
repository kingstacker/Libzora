## 如何测试

1. 打开上表中的书籍文件，在 GitHub 文件页面点击 **Download raw file** 下载，或克隆仓库后使用本目录文件。
2. 启动 Libzora，点击书库的“＋”导入 EPUB，可以多选六本一起导入。
3. 检查封面、标题、作者和目录，打开书籍测试阅读、搜索、书签及批注。
4. 测试 USB 传书时，连接 Kindle 并选择书籍发送；EPUB 转为 Kindle 支持的格式需要配置 Calibre。

本目录仅提供书籍文件，不包含预置书库数据库、账号、阅读进度或个人笔记。`SHA256SUMS.txt` 可用于核对下载文件是否完整。
